# МТС

## Описание

Метод предоставляет возможность проверки данных пользователя по абонентским базам операторов большой тройки. На основании результата проверки можно проводить полную идентификацию.

Необходимый scope: mts.

Необходимый набор документов: 

* passport_rus
* phone
* inn

Ссылка на документацию сервис-провайдера: (https://developers.mts.ru/mobile-id/documentation/verifikatsiya-si-verify)[https://developers.mts.ru/mobile-id/documentation/verifikatsiya-si-verify]
