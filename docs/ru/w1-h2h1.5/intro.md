# Введение {#введение}

Данный документ предоставляет описание протокола, предназначенного для host-2-host интеграции интернет магазинов с сервисом [Wallet One Checkout (“Единая касса”)](https://www.walletone.com/ru/merchant/). Интеграция посредством H2H протокола, позволяет осуществлять прием платежей без перехода плательщика на платежные страницы Wallet One, что в свою очередь позволяет более гибко управлять процессом оплаты, а также производить интеграцию в различные устройства, где по каким-либо причинам, невозможно использование традиционной платежной страницы. В документации приведены общие правила составления запросов и разбора ответов, описание всех методов, а также примеры реальных ситуаций, в которых может быть использовано API.

# Термины и определения {#термины-и-определения}

## Общие определения {#общие-определения}

**Мерчант** \- предприятие подключенное к системе Wallet One Checkout, осуществляющее прием платежей в свою пользу (ТСП), либо в пользу третьих лиц (Агрегатор).

**Инвойс (Invoice)[^1]** \- сущность, формируемая в учетной системе Wallet One с целью сохранения свойств “заказа”, таких как уникальный идентификатор заказа в системе учета интернет магазина, описание товара/услуги, стоимость, срок оплаты и прочие настройки, влияющие на процесс оплаты.

**Платеж (Payment) \-** сущность, формируемая в учетной системе Wallet One для сохранения уникальных свойств каждой попытки оплаты, включая ее статус (ожидает оплаты, успех, ошибка). 

**Способ оплаты \-** набор процедур по авторизации платежа, объединенный общим сценарием и, как правило, брендом, известным плательщику. Каждому способу оплаты Wallet One присваивается буквенный код из собственного справочника, который в дальнейшем используется при обращениях к API. 

Примеры способов оплаты: 

- CreditCardRUB \- банковские карты,   
- WalletOneRUB \- Единый кошелек,   
- CashTerminalRUB \- платежные терминалы,  
- другие.

Актуальный справочник способов оплаты публикуется на странице [документации](https://www.walletone.com/ru/merchant/documentation/#step4). Обратите внимание, не все способы оплаты поддерживают работу по протоколу Host-2-Host. 

**Платежный инструмент** \- конкретный счет/учетная запись, в рамках способа оплаты, используемого плательщиком. Например \- банковская карта 4111 1111 1111 1111, или номер телефон *\+7 (912) 345-67-89*.

**Авторизация платежа \-** набор действий, совершаемых платформой Wallet One с целью списания денежных средств с платежного инструмента и учета их на счету получателя.
