# Часто задаваемые вопросы

## KYC

KYC (Идентификация) - процесс подтверждения личности пользователя в банковской организации для расширения возможностей работы с кошельком и увеличения значений лимитов. Существует 2 уровня идентификации: упрощенная и полная идентификация. Изначально пользователю открывается анонимный кошелек. Упрощенная идентификация доступна через Госуслуги и ФНС, полную идентификацию можно пройти путем подачи заявки на видео звонок либо при личном посещении офиса банковской организации.

### Можно ли создать кошелек, минуя уровень ИД Аноним?

\-Нет, кошелек создается через метод **POST Wallet (POST /wallet)** с уровнем ИД - Аноним

### Можно ли "понизить" уровень ИД на кошельке пользователя?

\-Нет, кошелек с уровнем УПРИД не сможет стать анонимным. По аналогии, кошелек с уровнем ФУЛЛИД не сможет стать УПРИД или анонимным.

### Как понять, является ли актуальной текущая ИД у пользователя?

\-Когда у пользователя ИД становится невалидной (не соответствует текущим персональным данным пользователя), на кошелек пользователя накладываются ограничения, текущей ИД присваивается статус "EXPIRED". Для снятия ограничений, пользователю необходимо пройти новую идентификацию с новыми персональными данными.
Для получения информации о текущем статусе ИД, необходимо ориентироваться на ответ системы в API, на поля kycRequestStateId и kycStatus:

**GET /wallet/{walletNumber}/balance**

```json
{
    "userBalance": {
        "currencyId": 643,
        "amount": 0.00,
        "overLimitAmount": 0.00,
        "overdraft": 0.00,
        "availableAmount": 0.00,
        "safeAmount": 0.00,
        "kycLevel": 10,
        "kycRequestStateId": "EXPIRED"
    }
}
```

**GET  /users/external-users/{userExternalId}**

```json
{
    "walletNumber": 762368580099,
    "externalUserId": "bf08a486-c5fb-4b2e-91fe-b44e66c691ac",
    "restrictionTypes": [
        "IDENTIFICATION_OUTCOME"
    ],
    "kycStatus": "EXPIRED",
    "blocked": false
}
```

Если статус "**EXPIRED**", пользователя необходимо отправить на новую ИД.

### Что происходит, если пользователь меняет свои персональные данные и не проходит новую ИД с новыми персональными данными?

\-Если пользователь вносит изменения в свои персональные данные (например, ФИО, серия и номер паспорта и т.д.), система автоматически накладывает ограничения на использования кошелька (текущей ИД присваивается статус "EXPIRED"). Для снятия ограничений пользователю необходимо пройти ИД с новыми персональными данными или связаться с <support@w1.money>

### Как работает автоматическая проверка для пользователей, которым предстоит замена паспорта в 20/45 лет?

\-Система автоматически отслеживает даты рождения пользователей и сроки действия их документов. Если пользователю исполняется 20 или 45 лет, система автоматически накладывает ограничения на использование кошелька (текущей ИД присваивается статус "EXPIRED"). Для снятия ограничений пользователю необходимо пройти ИД с новыми паспортными данными.

### Что делать пользователю, если он столкнулся с трудностями в процессе прохождения идентификации?

\-Пользователь должен обратиться в службу поддержки <support@w1.money> . Специалисты службы поддержки помогут решить возникшие проблемы и ответят на все интересующие вопросы.
